# Internet Backyard Prototype

Design exploration repo for Internet Backyard's AI billing transaction primitive.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Useful Commands

```bash
npm run lint
npm run build
```

## Pages

- `/` - prototype index
- `/brief` - project framing and product context
- `/explorations` - visual direction placeholders
- `/primitive` - future transfer dialog primitive

See `goal.md` for the full product goal and evaluation criteria.
